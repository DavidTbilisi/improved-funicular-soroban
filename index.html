Click any bead to move it. Each column has 1 sky bead (worth 5) and 4 earth beads (worth 1 each). Integer places sit left of the green point with upright pegs (Apple = ones, Banana = tens…). L3 Deep Pack — scenes for the current number

The number-codec-ladder's archival codec (candidate): the digit string is chunked into [cell][action][cell] scenes of 5 digits — a cell is a peg-matrix percept (audio peg = tens, visual peg = units), the action digit comes from the cube faces (0 = static contact, 1–4 = drive-through / splatter / abduct / drench, 5 = thorn-wrap, 6–9 = the same four flaming 🔥). Two scenes + a checksum seal (digit-sum mod 9, remainder 0 written as 9) = one locus = 10 digits. Partial tails use shorter grammar (4 = cell·action·face, 3 = cell·action, 2 = cell, 1 = face). Seals are in scope at ≥8 digits — below that they render dimmed, practice only. Hex mode packs the integer part as bytes from the 16×16 matrix (2 byte-cells per scene, contact binder, 4 bytes + seal per locus); the hex seal is the nibble-sum mod 15, 0 written as F (registered convention — the seal's base-general form, mod b−1 with weighted tier mod 17).

A–Z food peg columns
