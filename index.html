Working the board

Click any bead to move it. Each column has 1 sky bead (worth 5) and 4 earth beads (worth 1 each). Integer places sit left of the green point with upright pegs (Apple = ones, Banana = tens…). Decimal places sit right of the point with flipped pegs reusing the same foods (flipped Apple = tenths, flipped Banana = hundredths…). Under each column the cube faces show the digit as one percept: earth beads = 🚕🍊👽🌊, sky bead = 🌹, so 8 is 🌹👽 (rose + alien).

Keyboard arithmetic. Each key is a literal bead move, laid out as the digit's die face — center 1, left 2, top 3, bottom 4, right 5 (the rose/heaven bead). Use ←/→ (or G/H) to focus any column — integer or decimal; a carry out of the tenths crosses the point into the ones. Q resets to 0. The right hand adds the die cross — K=1 (center), J=2 (left), I=3 (top), ,=4 (bottom) push earth beads, L=5 (right) sets the heaven bead, and U = carry (+10). The left hand subtracts the same cross — D S E C pull 1–4, F clears the heaven bead, R = borrow (−10). Chords: hold the cells together to place 6–9 in one gesture, exactly as the die lights them — L+J = 7, L+I = 8, L+, = 9, L+K = 6. A move that can’t be made directly on the current rod is rejected and flagged, with the correct complement suggested — you compose it yourself, e.g. +3 on a 4 → L then S (+5 −2). Every move is undoable with the Undo button.
Input mode: just start typing a number — press any digit (or .) to jump into the value field, then Enter to place it on the soroban (Esc to cancel). The number row types numbers; the home row moves beads.

L3 Deep Pack — scenes for the current number

The number-codec-ladder's archival codec (candidate): the digit string is chunked into [cell][action][cell] scenes of 5 digits — a cell is a peg-matrix percept (audio peg = tens, visual peg = units), the action digit comes from the cube faces (0 = static contact, 1–4 = drive-through / splatter / abduct / drench, 5 = thorn-wrap, 6–9 = the same four flaming 🔥). Two scenes + a checksum seal (digit-sum mod 9, remainder 0 written as 9) = one locus = 10 digits. Partial tails use shorter grammar (4 = cell·action·face, 3 = cell·action, 2 = cell, 1 = face). Seals are in scope at ≥8 digits — below that they render dimmed, practice only. Hex mode packs the integer part as bytes from the 16×16 matrix (2 byte-cells per scene, contact binder, 4 bytes + seal per locus); the hex seal is the nibble-sum mod 15, 0 written as F (registered convention — the seal's base-general form, mod b−1 with weighted tier mod 17).
